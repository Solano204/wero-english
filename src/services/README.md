# services

Lo que habla con el teléfono o con afuera, cada uno con una API chica y documentada: audio, voz, música, descargas, anuncios, notificaciones, háptica, media y cuenta (auth, borrado, consentimiento).
No escribe SQL (usa `data/repos`) ni sabe de pantallas: importa `data`, `domain`, `theme`, `config`, `types` y el mapa de medios.
