# app

El arranque de la app: `App.tsx` (proveedores, fuentes, splash), `arranque/` (BootScreen: abre la base, siembra el catálogo, prepara el audio) y `navegacion/` (RootNavigator, TabNavigator y su barra).
Aquí solo se definen rutas y navegadores; ninguna regla de negocio. Puede importar cualquier capa; nadie importa `app`.
